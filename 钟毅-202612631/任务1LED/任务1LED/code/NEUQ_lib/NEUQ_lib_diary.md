## 此文件为NEUQ_STM32F407VET6_Opensource_Library软件的编写日志

*作者：张瑞*

*版本控制命名规则：MAJOR.MINOR.PATCH*


| 层级              | 含义                         | 触发条件                            |
| ----------------- | ---------------------------- | ----------------------------------- |
| `MAJOR`（主版本） | **重大变更**，可能导致不兼容 | 比如更换 MCU 平台、改动库接口命名等 |
| `MINOR`（次版本） | **新增功能**，向后兼容       | 增加一个外设驱动、新增算法模块等    |
| `PATCH`（修订号） | **修复 Bug / 小改动**        | 修复某外设初始化问题、代码优化等    |
